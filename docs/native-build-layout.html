Host export requested

  • Use the full backend when it is loadable.
  • Otherwise fall back to _host_backend.
  • Supports local ClickHouse benchmarking on CPU-only machines.

Ring export requested

  • Load only _native_backend.
  • Fail with the full-build command when CUDA support is absent.
  • Never present a partial ring implementation.
